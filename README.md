# Student Management System

A full-stack CRUD web application for managing student records.

## Features

- Add new students
- View student records
- Edit student details
- Delete student records
- Search students
- Responsive user interface
- REST API integration

## Technologies Used

- HTML
- CSS
- JavaScript
- Node.js
- Express.js
